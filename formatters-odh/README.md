# formatters-odh

**Java module:** `it.unibz.odh.formatters.odh`

## Responsibility

Plugin with formatters specific to Open Data Hub data shapes (multilingual text, coordinates, nested arrays, ...).

## Dependency rule

Depends only on table-api. Kept separate from the basic formatters because it changes for different reasons (Common Closure Principle).

**Maven dependencies:** `table-api`
