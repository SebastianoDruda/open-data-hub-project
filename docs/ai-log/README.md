# AI interaction log

The assignment states: *"Use of AI: when the group uses AI, it should know and understand everything
that was created. All the prompts and interactions should be shared in the end."*

This folder is that record. **One file per working session**, named
`YYYY-MM-DD-<author>-<topic>.md`, using the structure below.

```markdown
# <date> – <topic>

- **Author:** who drove the session
- **Tool / model:** e.g. Claude Code (Claude Opus 5.5), ChatGPT (GPT-x), Copilot
- **Goal:**

## Prompts
Verbatim prompts written by the student (or a link to the exported transcript).

## What the AI produced
Short summary + links to commits / files.

## What we changed, rejected or verified ourselves
Decisions taken by the team, corrections, things the AI got wrong.
```

Full transcripts can be added in `transcripts/` when the tool allows exporting them.
