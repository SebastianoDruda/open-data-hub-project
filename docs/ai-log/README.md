# AI interaction log

The assignment states: *"Use of AI: when the group uses AI, it should know and understand everything
that was created. All the prompts and interactions should be shared in the end."*

This folder is that record: **one file per working session**, named `YYYY-MM-DD-<author>-<topic>.md`.

## Entry structure

```markdown
# Session NN – <topic>

| | |
|---|---|
| **Date** | YYYY-MM-DD |
| **Author** | who drove the session |
| **Tool / model** | e.g. Claude Code (Claude Opus 5.5) |
| **Goal** | one sentence |

## 1. Requests to the assistant
Numbered list of what was asked, with the intent of each request.

## 2. Outcome
What was produced, grouped by topic, with links to files and commits.

## 3. Decisions and verification by the team
What the team decided, changed, rejected or checked.

## 4. Open points
What remains to be done or discussed.
```
